= Learn about the docs.netapp.com MCP server
:hardbreaks:
:nofooter:
:icons: font
:linkattrs:
:imagesdir: ./media/

[.lead]
The docs.netapp.com MCP server provides a standardized, agent-ready integration layer in front of existing NetApp documentation and Retrieval-Augmented Generation (RAG) services. It allows AI agents, such as GitHub Copilot in Visual Studio Code, Claude Desktop, and custom Python AI agents, to interact with enterprise technical knowledge using natural language without requiring direct REST API integration or custom pipeline development.

By providing structured access to NetApp documentation, the docs.netapp.com MCP server enables AI agents to:

* Discover relevant documentation
* Retrieve complete document content
* Generate answers based on documentation (RAG based answer generation)
* Produce grounded, verifiable responses

== Use cases

The docs.netapp.com MCP server enables you to:

* Ask natural language questions about NetApp products

* Get answers grounded in official documentation

*  Avoid building custom search or RAG pipelines

* Ensure responses are accurate and verifiable

It provides three primary tools for different use cases:

[cols="1,1,3, options="header"]
|===
| Tool name | Use case | Description

a| `netapp_docs_search`
a| Search NetApp documentation and return relevant pages.

a| Discovers relevant documentation using keyword and natural language queries. 

* *Input:* A query using keywords and natural language
* *Output:* A list of documents with title, summary, and URL

a| `netapp_docs_fetch`
a| Retrieve full documentation content for a URL. 

Used to extract steps, explanations, and details.

a| Retrieve full, structured document content by article URL. 

* *Input:* NetApp documentation URL
* *Output:* Structured text content (title, summary, and article)

a| `netapp_docs_ask`
a|  Generate answers using RAG. 

Used when combining information across multiple documents.
a| Generates synthesized, documentation-grounded answers using RAG. 

* *Input:* A question
* *Output:* A synthesized answer with references

|===


== How the docs.netapp.com MCP server works

The MCP server and AI agents interact to retrieve and return grounded responses from official NetApp documentation. 

* The AI agent sends a request to the MCP server
* The MCP server retrieves relevant documentation
* The system returns a structured, grounded response

AI agents use the following deterministic workflow when interacting with the server:

. Use netapp_docs_search to locate relevant documentation.
. Select the most relevant results.
. Use netapp_docs_fetch to retrieve full document content.
. Extract steps, explanations, or key details.
. Optionally use netapp_docs_ask to synthesize answers across documents.

This ensures that responses are grounded in authoritative documentation, AI hallucinations are minimized, and answers are structured and accurate.

== Requirements

* *Authentication*: Access is managed through NetApp API Management (APIM). Trusted internal requests are authenticated through network IP filtering. External or partner requests utilize an APIM subscription key.
* *Client Compatibility*: Supported on any MCP-compliant client environment, including Visual Studio Code (GitHub Copilot), Claude Desktop, and Python-based agent frameworks.
* *Terms of Service*: Usage is subject to official NetApp documentation terms and access governance policies.

== Limitations

* *Content Scope*: The MCP server queries publicly published NetApp technical documentation. It does not access private tenant data or internal user profile information.
* *Continuous Refresh*: Content indexed by the underlying search and RAG orchestrator is updated incrementally as technical documentation is published.
